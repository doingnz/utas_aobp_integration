AOBP Integration — Test Harness

Runs js/aobp.js exactly as the REDCap survey page runs it, against a real BP+ or the SDK simulator. The panel on the left is a stand-in for the aobp_visit instrument: the same element IDs, and one input per REDCap field. Whatever the module writes into those fields is what REDCap would have stored.

This page is not part of the deployed module. REDCap serves only the module directory; this harness exists so the integration can be exercised without a REDCap development instance. It needs a local web server — python -m http.server 8080 from the module folder, then open /test/harness.html. ES modules and Web Serial both refuse to run from file://.
