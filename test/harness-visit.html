Reproduces the aobp_visit instrument from AOBPDEV_DataDictionary_2026-08-31.csv: one page, both measurements, the standing block gated by branching logic on sys_standing_required. Runs js/aobp.js unmodified.

Why this exists alongside harness.html. That one is a flat stand-in with a single set of controls. This one has two blocks on one page, which is what the dictionary describes — and it is the arrangement in which duplicate element ids collide. Branching here hides the standing block with display:none and leaves it in the DOM, exactly as REDCap does.
